\#\# Core Data Rules

\- Mandarat is the source of execution items.  
\- Project is the execution context.  
\- Every execution item must have project\_id (no orphan tasks).  
\- Task completion is stored as logs (execution\_log), not by editing the task itself.  
\- Week/Day are time slices (views), not parent containers that own tasks.  
\- A default "Inbox" project must exist for fast capture; items must be assignable later.
